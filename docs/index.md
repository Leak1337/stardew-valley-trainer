---
title: Stardew Valley Trainer
description: In-game trainer for Stardew Valley 1.6.15
---

[Deutsch](german.html)

Press **F5** in a loaded single-player save to open the trainer. The menu follows your game language and supports English and German.

| Tab | Features |
| --- | --- |
| Player | Gold, health, energy, backpack slots, and player-only movement speed |
| World | Teleport, return to your last departure point, advance or freeze time, and set tomorrow's weather |
| Items | Search for items by name or ID and add them to your inventory |
| Farm | Water soil, care for animals, repair fences, and finish running machines |
| Skills | Add XP to the five base-game skills |
| Friendship | Add friendship points for villagers you've already met |
| Gifts | Search villagers by name and see their best gifts, birthday, location, hearts, and gift counts |
| Recipes | Unlock cooking and crafting recipes |
| Community | Get bundle requirements, complete bundles or the Community Center, find museum donations, and finish quests |
| Mods | See loaded add-ons, mark waypoints, and filter Expanded items and villagers when the mod is detected |
| Equipment | Change tool tiers, choose a mine floor, and place a ladder down |
| Fancy | Emotes, light show, and adjustable temporary luck and magnetism boosts |

SMAPI is the only required add-on. The trainer also reads compatible mod content from the game. Enter your own amounts for gold, items, XP, and friendship points.

Stardew Valley Expanded adds fast travel and dedicated content filters. Ridgeside Village adds item, villager, and recipe filters. Machines listed by Automate are skipped by the trainer's machine completion action. See the [compatibility list](https://github.com/Leak1337/stardew-valley-trainer#optional-mod-compatibility) for details.

The trainer was built for Stardew Valley **1.6.15** and **SMAPI 4.1.10**. Find the [source and installation instructions on GitHub](https://github.com/Leak1337/stardew-valley-trainer#build-and-install).
